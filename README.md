# ProyectoFinalMedina

Aplicación e-commerce de autos desarrollada con React y Firebase.

## Tecnologías utilizadas

- React
- React Router DOM
- Firebase Firestore
- Context API
- CSS3
- Vite

## Funcionalidades

- Listado dinámico de productos desde Firebase
- Filtrado de productos por categorías
- Vista detallada de cada producto
- Carrito de compras global con Context API
- Control de stock mediante ItemCount
- Checkout con formulario de compra
- Generación automática de órdenes
- Guardado de órdenes en Firebase Firestore
- Navegación SPA con React Router

## Instalación y ejecución

Clonar el repositorio:

```bash
git clone <URL_DEL_REPOSITORIO>
```

Instalar dependencias:

```bash
npm install
```

Ejecutar el proyecto:

```bash
npm run dev
```

## Base de datos

Colecciones utilizadas en Firebase Firestore:

- `products`
- `orders`
